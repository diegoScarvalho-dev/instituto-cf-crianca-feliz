# 👧🧒 Instituto CF – Criança Feliz

Projeto acadêmico desenvolvido como atividade prática da graduação em **Engenharia de Software**, com o objetivo de aplicar conceitos fundamentais de desenvolvimento web utilizando **HTML5 e CSS3**.

O projeto simula o site institucional de uma ONG fictícia chamada **Instituto CF – Criança Feliz**, voltada para ações sociais relacionadas à educação, alimentação, voluntariado e apoio à comunidade.

## 🎯 Objetivo da atividade

A atividade teve como objetivo colocar em prática conceitos relacionados à estruturação e desenvolvimento de páginas web, incluindo:

- Estrutura semântica do HTML5;
- Hierarquia de títulos;
- Navegação entre páginas;
- Acessibilidade;
- Utilização de imagens e textos alternativos;
- Formulários HTML;
- Validações nativas do HTML5;
- Organização de arquivos e diretórios;
- Estilização utilizando CSS3;
- Responsividade básica;
- Validação da estrutura HTML.

## 🖥️ Páginas desenvolvidas

### `index.html`
Página inicial do Instituto CF – Criança Feliz, contendo apresentação institucional, missão e informações de contato.

### `projetos.html`
Apresentação dos projetos sociais desenvolvidos pela ONG, incluindo:

- Projeto Alimentação;
- Projeto Educação;
- Doações;
- Voluntariado.

### `cadastro.html`
Formulário destinado ao cadastro de interessados em participar das ações da ONG.

Foram utilizados campos para:

- Nome;
- E-mail;
- Data de nascimento;
- CPF;
- Telefone;
- Endereço;
- Cidade;
- Estado;
- CEP.

## ✅ Validação de formulários

O formulário utiliza recursos nativos do HTML5, como:

- `required`
- `pattern`
- `type="email"`
- `type="date"`
- `type="tel"`

Foram aplicados padrões de validação para campos como CPF, telefone e CEP.

## ♿ Acessibilidade e HTML semântico

Durante o desenvolvimento foram utilizadas tags semânticas como:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

As imagens também possuem o atributo `alt`, contribuindo para a acessibilidade do conteúdo.
